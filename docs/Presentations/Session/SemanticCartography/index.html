Achievement Unlocked

Classification
  • Classification is for known labels
  • Clustering is an unsupervised form of classification.

Grouping data into known categories based on features of each item

  • Can be used for:
    • Grouping items with shared properties together
    • Identifying which known group a new item belongs to
    • Normalization of input/output
  • Usually based on a training set of labeled data
    • The model learns the features that define each category
    • New items are classified based on learned features
    • Classification is a supervised learning problem

Introduce classification as the supervised-learning problem of assigning an input to one of several known categories. Position it as the cousin of the clustering work that follows: classification starts with labels, while clustering asks whether useful groups can be discovered without them.

Assigning Meaningful Labels
  • Start with known labels:
    • Spam or not spam
    • Defect or no defect
    • Support ticket category
    • Image contents
  • The model is trained from labeled examples
  • Then it predicts the best label for new inputs

The ingredients to look for in real systems: labeled examples, features, target classes, a training process, and a prediction step.

Shape of a Classification Problem

  • Labeled examples show the model what the right answer looks like

    • Each example includes input data plus the correct label

  • Features are the details the model is allowed to use

    • Measurements, properties, words, pixels, counts, or categories
    • Chosen because they may help separate one label from another

  • Target classes are the labels the model is allowed to predict

    • The known categories we care about
    • The output must be one of these classes

  • Training searches for a pattern from features to target class

  • Prediction applies that pattern to an unlabeled input

Decision Boundaries

Use the visual to explain that classifiers divide feature space into regions where different labels are predicted. This bridges the workshop's earlier geometry and search ideas into machine-learning style pattern matching.

  • A classifier divides feature space into regions

  • Each region predicts a different target class

  • The line between regions is a decision boundary

  • New inputs are classified by where they land

  • Different algorithms draw different kinds of boundaries

Rule-Based vs Tree-Based

Rule-based classifiers use explicit if/then rules, usually written by people or extracted from domain knowledge. They are easy to inspect because each rule stands alone, but they can become brittle when the data has many interactions or fuzzy exceptions. Tree-based classifiers learn a hierarchy of rules from labeled examples. Each split asks a feature question, each path combines several decisions, and each leaf predicts a target class. A single decision tree remains fairly explainable, while random forests combine many trees to improve generalization at the cost of less direct explanation.

  • Decision trees are readable classification models

  • Each split asks a question about a feature

  • Each branch narrows the possible class

  • Each leaf predicts a target class

  • Random forests use many trees and combine their votes

  • The tradeoff: less explainable, often better generalization

Linear Classifiers

Explain logistic regression and linear support-vector machines as algorithms that try to separate classes with a weighted combination of features. Connect this back to the audience's existing mental model of equations, weights, and boundaries rather than diving into training math.

  • Linear classifiers separate classes with a weighted feature score

  • Each feature contributes to the final decision

  • The boundary is a line or flat surface in feature space

  • Logistic regression estimates the probability of a class

  • Linear SVMs look for a separating boundary with margin

Instance-Based Classifiers

Introduce k-nearest neighbors as the classifier that predicts from similar known examples nearby. This slide should prepare the audience for the clustering section, where distance and similarity become the central tools.

  • Instance-based classifiers keep examples instead of learning a compact rule

  • k-nearest neighbors asks: which labeled examples are closest?

  • Nearby examples vote on the label for a new item

  • The core idea is distance or similarity

  • That same idea becomes central in clustering

Probabilistic Classifiers

Introduce Naive Bayes as a lightweight classifier that estimates which label is most likely given the observed features. Use it to show that some algorithms produce confidence-like scores, not just a final class name.

  • Probabilistic classifiers estimate which label is most likely

  • Naive Bayes combines evidence from observed features

  • It is lightweight and useful for text-like signals

  • The output can be a ranked set of class scores

  • The final label is the highest-scoring class

Evaluating Classification Results

Explain that accuracy alone can mislead. Introduce the confusion matrix, precision, recall, and false positives/false negatives as the practical vocabulary for deciding whether a classifier is useful in context.

  • Accuracy alone can hide important mistakes

  • A confusion matrix shows what was predicted versus what was true

  • False positives and false negatives often have different costs

  • Precision asks whether positive predictions are trustworthy

  • Recall asks whether the important positives were found

Classification vs Clustering

Close the subsection by making the contrast explicit: classification asks which known label fits this item, while clustering asks what groups seem to exist at all. This sets up the upcoming hands-on clustering exercise.

  • Classification starts with known target classes

  • The question is: which known label fits this item?

  • Clustering starts without those labels

  • The question is: what groups seem to exist?

  • Both use feature space, but they ask different questions

Clustering

Clusters contains items more similar to each other than to those in other clusters

  • Key to use: Experiment

  • Unsupervised machine learning technique
  • Clusters form around centroids (geometric center)
  • Data points are grouped based on their similarity
    • Minimize the error (distance from centroid)
  • Advantages
    • No need to define a distance threshold
  • Disadvantages
    • Quality is use-case dependent
    • Often requires the number of clusters to be specified

K-Means Clustering

Explain k-means as an iterative clustering algorithm: choose k, assign each point to the nearest centroid, move the centroids to the middle of their assigned points, and repeat until the assignments stabilize. Keep the focus on the algorithmic loop rather than the distance formula.

  • k-means groups points around centroids

  • Start by choosing k, the number of clusters

  • Assign each point to the nearest centroid

  • Move each centroid to the middle of its assigned points

  • Repeat until the assignments stop changing much

Choosing K and Reading the Result

Explain that k-means requires the number of clusters up front, so the algorithm is simple but the modeling question is not automatic. Mention that different choices of k tell different stories about the same data.

  • k-means needs the number of clusters up front

  • The algorithm can run cleanly even when k is the wrong question

  • Different values of k tell different stories about the same data

  • Use domain context and experimentation to choose a useful grouping

Hierarchical Clustering

Introduce hierarchical clustering as building a tree of similarity: points merge into small groups, small groups merge into larger groups, and the presenter can choose where to cut the tree. Keep the focus on the algorithmic shape rather than distance-formula details.

  • Hierarchical clustering builds a tree of similarity

  • Nearby items merge into small groups

  • Small groups merge into larger groups

  • Cutting the tree at different heights gives different cluster counts

  • This is useful when the right number of groups is not obvious

DBSCAN

Introduce DBSCAN as a density-based algorithm that finds crowded regions and treats isolated points as noise. Contrast it with k-means: DBSCAN does not require k up front and can discover irregular cluster shapes.

  • DBSCAN finds dense regions in feature space

  • Crowded neighborhoods become clusters

  • Sparse isolated points are treated as noise

  • It does not require k up front

  • It can find irregular shapes that k-means misses

Evaluating Clustering Results

Explain that clustering has no single confusion-matrix equivalent when labels are unknown. Introduce practical evaluation questions: are points inside a cluster similar, are different clusters separated, and does the grouping help the real task?

  • Clustering often has no known correct label

  • Evaluation is about whether the grouping is useful

  • Good clusters are cohesive inside

  • Good clusters are separated from each other

  • The final test is whether the grouping helps the real task
